# 可直接发给老师/师兄的数据确认与需求清单

老师/师兄好，我准备在现有工业机器人绝对定位测量数据基础上，研究“真实数据校准的
机制引导安全残差强化学习”，重点从单点监督误差预测扩展到连续路径补偿、平滑性、
可执行性和跨日期/工作空间鲁棒性。为了避免误用数据和重复已有论文，希望确认并补充
以下信息。

## A. 现有数据元数据（优先）

1. `x-real/y-real/z-real` 由什么设备测得？例如激光跟踪仪、摄影测量或思看扫描；设备
   型号、标称精度和标定方式是什么？
2. 各文件关节角、TCP 位置和姿态的单位、坐标系、正负方向是什么？姿态使用 ABC、RPY、
   旋转向量还是四元数？旋转顺序是什么？能否提供 base/world/tool/TCP 变换？
3. `data01...data11`、`data_all`、建模/验证、手摇10个、理论、补偿前/补偿后分别对应
   什么机器人、日期、工作空间、轨迹和实验条件？`data_all` 是否只是子文件合并？
4. 每行是独立静态点还是连续采样？是否有同一点重复测量？`Sequence/Time` 是否保持
   实际执行顺序？
5. 已发表论文具体使用了哪些文件、训练测试划分、方法和最终补偿指标？哪些创新点和
   数据测试集应避免重复？能否提供论文与实验配置？
6. 各机器人准确型号、关节限制、真实 TCP、工具负载、控制周期、厂家 DH/标定参数、
   URDF/CAD 是否可以提供？
7. 是否保留原始连续机器人程序和逐时刻外部测量，而不仅是整理后的离散 CSV？

特别希望确认：

- `UR5_DATA/data08.csv` 的实测表头为 `z-real,y-real,x-real`，是仅表头顺序错误，还是
  数据列也需要重排？
- 根目录 `train00/test00` 属于哪台机器人、哪个坐标系，为何误差量级与其他数据不同？
- KR210 2025-05-22 与 2025-05-29 是否使用相同 TCP、负载、基坐标和测量流程？
- KR240 2025-07-17/18 是否是严格的建模/次日验证关系？
- MPI/TXT/CAM 中哪些是同一路径的理论、补偿前和补偿后配对？

## B. 可获得的历史日志/新导出（不需要我现场控制）

如课题组或工厂有历史记录，希望按优先级获取：

1. 连续轨迹日志：timestamp、q/qdot、commanded/actual TCP、速度、程序段和报警。
2. 人工/自动补偿动作、补偿前后程序和外部实测误差。
3. 同一路径的多次重复，以及不同日期、TCP、工具负载和工作空间记录。
4. 工程师人工调轨迹的版本历史；这最接近真实 expert action。
5. 若有滚边数据：同步 6D F/T、路径/姿态/速度、道次、板件/夹具 frame、材料/厚度、
   roll-in/out、hem thickness 和缺陷/合格标签。
6. 若有 Abaqus/LS-DYNA：输入文件、材料/摩擦/接触条件及力、位移、质量输出。

## C. 数据使用说明

现有离散数据只用于校准静态误差模型和仿真分布，不会称为 offline RL 数据；RL 主结果
会明确标为 data-calibrated simulation，不声称真实工厂部署。真实历史补偿前后记录若
能确认语义，将仅作为未参与训练的外部 case study。
